# VHPOP example files

The `.pddl` files in this folder are copied unchanged from the `examples/`
folder of [VHPOP](https://github.com/hlsyounes/vhpop), the Versatile Heuristic
Partial Order Planner by Håkan L. S. Younes, at commit
`cf27db2ed46f8bd64cb78fe256cb5cf3ad8174cf`. Many are PDDL versions of the
domains from the UCPOP distribution; others come from the AIPS-98 and IPC-2000
planning competitions and from Nguyen & Kambhampati (2001), as noted in the
files' own comments.

VHPOP is distributed under the GNU General Public License, version 2; see
[`COPYING`](COPYING). These files are test inputs only. They are not compiled
into the `pddl` crate and are excluded from its published package.
