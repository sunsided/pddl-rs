# Potoroo example files

`gripper-40.pddl`, `logistics-e.pddl` and `logistics-f.pddl` are copied
unchanged from the `examples/` folder of
[Potoroo](https://github.com/HarrisonOates/potoroo), a partial-order
causal-link planner by Harrison Oates, at commit
`1264ed6cefaf3b72233366c44a3a9ac5303b43c2`. Potoroo's other examples are the
VHPOP files in [`../vhpop`](../vhpop).

They are licensed under the Apache License, Version 2.0; see
[`LICENSE`](LICENSE) and [`NOTICE`](NOTICE). These files are test inputs only.
They are not compiled into the `pddl` crate and are excluded from its published
package.
