# Parser snapshots

Generated by `tests/corpus_snapshots.rs` from the files in `../vhpop/` and `../potoroo/`.
Each snapshot has the name of its source file: a `.pddl` snapshot is that file parsed and
pretty-printed, and a `.err` snapshot is the error message for a file the parser rejects. They are derived from the original
files and fall under the same licences (see `../vhpop/COPYING` and `../potoroo/LICENSE`).

Regenerate after an intended parser or printer change, then review the diff:

```sh
UPDATE_SNAPSHOTS=1 cargo test --all-features --test corpus_snapshots
```
